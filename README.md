# NovaCart + Customer Account Page

This project combines the NovaCart fixed project with the Customer Signup/Account page.

## Routes

- `/` — NovaCart home
- `/login` — existing NovaCart login
- `/customer-signup` — Customer account creation page
- `/vendor` — Vendor dashboard
- `/customer` — Customer dashboard

## Run

```bash
npm install
npm run dev
```

No `node_modules` is included in this ZIP.


Customer flow: Home -> Customer -> /customer-login -> Create an account -> /customer-signup
